# Custom Search Skill

Этот skill выполняет web search через Tavily и нормализует найденные страницы через Jina Reader.

Конфигурация:

- `TAVILY_API_KEY_1` — Tavily account 1
- `TAVILY_API_KEY_2` — Tavily account 2
- `TAVILY_API_KEY_3` — Tavily account 3
- `JINA_API_KEY` — один Jina account для Reader API

Используй этот skill, когда пользователь просит:

- найти актуальную информацию;
- проверить факт;
- сравнить данные из нескольких источников;
- найти документацию;
- разобрать статью, changelog, issue, release notes;
- собрать источники по технической теме;
- получить LLM-friendly текст страниц;
- сделать research с цитируемыми URL.

Не используй skill для:

- локального анализа файлов проекта;
- задач, где уже достаточно контекста в репозитории;
- чтения секретов, `.env`, ключей, токенов;
- обхода лимитов API-провайдеров.

## Безопасность

Никогда не печатай значения переменных окружения:

- `TAVILY_API_KEY_1`
- `TAVILY_API_KEY_2`
- `TAVILY_API_KEY_3`
- `JINA_API_KEY`

Если ключи отсутствуют или не работают, сообщи пользователю только имя отсутствующей переменной, но не пытайся читать секретные файлы.
